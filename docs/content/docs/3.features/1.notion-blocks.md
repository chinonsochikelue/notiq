# Notion-Style Blocks

Notiq includes **BlocksKit**, a full suite of Notion-style block components built directly into the core framework. In Tiptap, block handles and multi-column layouts require proprietary or paid Pro extensions; in Notiq, they are 100% open-source and first-class.

---

## 1. Quick Setup with BlocksKit

Enable block capabilities by registering `BlocksKit`:

```tsx
import { useNotiq, NotiqContent } from '@collabchron/notiq'
import { StarterKit } from '@collabchron/notiq/starter-kit'
import { BlocksKit } from '@collabchron/notiq/blocks-kit'

export function NotionStyleDoc() {
  const editor = useNotiq({
    extensions: [
      StarterKit,
      BlocksKit.configure({
        handles: true,      // 6-dot drag grip handle
        slashMenu: true,    // Quick slash palette (/)
        columns: true,      // Multi-column layouts
        callouts: true,     // Callout alert boxes
        toggles: true,      // Collapsible toggle sections
      }),
    ],
  })

  return <NotiqContent editor={editor} />
}
```

## 2. Block Drag Handles (6-Dot Grip)

Whenever a user hovers over any top-level or nested block in the editor, Notiq calculates the bounding box and renders a floating **Block Handle**:

- **Click**: Selects the entire block and displays the block transformation menu (Turn into H1, H2, Code block, Delete, Duplicate).
- **Drag**: Initiates smooth HTML5 drag-and-drop reordering with a visual insertion line indicator.
- **Alt + Drag**: Duplicates the dragged block to the drop target.

### Customizing the Handle

You can supply your own custom React component for the handle:

```tsx
BlocksKit.configure({
  handleComponent: ({ blockId, onDragStart, onClick }) => (
    <div
      draggable
      onDragStart={onDragStart}
      onClick={onClick}
      className="p-1 rounded hover:bg-zinc-800 cursor-grab text-zinc-500 hover:text-zinc-200"
    >
      <GripVerticalIcon className="w-4 h-4" />
    </div>
  ),
})
```

## 3. Slash Command Menu (`/`)

Typing `/` on any empty block triggers the command palette popup:

- Filter commands dynamically with fuzzy search.
- Insert headings, lists, quotes, tables, code blocks, dividers, callouts, or column layouts.
- Keyboard accessible: Navigate with <kbd>&uarr;</kbd> and <kbd>&darr;</kbd>, press <kbd>Enter</kbd> to execute, <kbd>Escape</kbd> to dismiss.

```tsx
// Programmatic trigger
editor.chain().focus().openSlashMenu().run()
```

---

## 4. Multi-Column Layouts

Notiq supports fluid multi-column grids:

```ts
// Insert a 2-column or 3-column layout
editor.chain().focus().insertColumns({ cols: 2 }).run()
```

Users can drag blocks between columns, resize columns via drag dividers, or collapse them on mobile screens automatically.

---

## 5. Callouts & Toggles

```ts
// Insert an information callout
editor.chain().focus().insertCallout({
  variant: 'info', // 'info' | 'warning' | 'success' | 'danger'
  icon: '💡',
}).run()

// Insert collapsible toggle
editor.chain().focus().insertToggle({
  title: 'Click to expand hidden notes',
  open: false,
}).run()
```
