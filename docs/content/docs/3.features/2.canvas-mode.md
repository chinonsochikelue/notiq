# Infinite Spatial Canvas

Traditional editor frameworks force you to choose: either a standard linear document editor (like Google Docs or Notion), or an infinite visual whiteboard (like Miro, FigJam, or Heptabase).

**Notiq bridges both in one unified runtime.**

With Notiq's **CanvasKit**, you can toggle any document into a 2D spatial canvas or embed interactive rich text cards on an infinite grid.

---

## 1. Quick Setup with CanvasKit

```tsx
import { useNotiq, NotiqContent } from '@collabchron/notiq'
import { StarterKit } from '@collabchron/notiq/starter-kit'
import { CanvasKit } from '@collabchron/notiq/canvas-kit'

export function SpatialWorkspace() {
  const editor = useNotiq({
    extensions: [
      StarterKit,
      CanvasKit.configure({
        mode: 'canvas', // 'document' | 'canvas' | 'split'
        grid: true,
        snapToGrid: 16,
        minZoom: 0.1,
        maxZoom: 3.0,
      }),
    ],
  })

  return (
    <div className="w-screen h-screen">
      <NotiqContent editor={editor} className="w-full h-full" />
    </div>
  )
}
```

---

## 2. Switching View Modes Dynamically

You can toggle between linear document mode and spatial canvas mode at runtime without losing document state or cursor position:

```ts
// Switch to canvas mode
editor.commands.setCanvasMode('canvas')

// Switch back to linear document mode
editor.commands.setCanvasMode('document')

// Toggle current mode
editor.commands.toggleCanvasMode()
```

When switching to canvas mode:
- Top-level blocks are mapped onto spatial card nodes with `(x, y, width, height)` coordinates.
- Rearranging cards updates their spatial coordinates, preserved alongside document content in the serialized JSON.

---

## 3. Panning, Zooming & Viewport Control

CanvasKit exposes full viewport manipulation via chained commands:

```ts
// Zoom controls
editor.chain().zoomIn().run()
editor.chain().zoomOut().run()
editor.chain().resetZoom().run()
editor.chain().setZoom(1.5).run()

// Pan controls
editor.chain().panTo({ x: 250, y: 400, smooth: true }).run()
editor.chain().fitToView().run()
```

---

## 4. Node Connectors & Mind-Mapping

Connect two spatial cards with bezier or straight visual edges:

```ts
editor.commands.connectNodes({
  sourceId: 'card-1',
  targetId: 'card-2',
  label: 'depends on',
  style: 'dashed',
})
```

Edges dynamically re-route around obstacles as cards are moved on the canvas.
