# StarterKit

`StarterKit` bundles the most essential rich text extensions into a single convenient import, including typography, list formatting, headings, code blocks, and undo/redo history.

---

## 1. Quick Start

```tsx
import { useNotiq } from '@collabchron/notiq'
import { StarterKit } from '@collabchron/notiq/starter-kit'

const editor = useNotiq({
  extensions: [StarterKit],
})
```

---

## 2. Bundled Extensions

`StarterKit` includes the following extensions out of the box:

| Extension | Type | Default Shortcut | Commands |
| :--- | :--- | :--- | :--- |
| `Bold` | Mark | <kbd>Mod+B</kbd> | `toggleBold()`, `setBold()`, `unsetBold()` |
| `Italic` | Mark | <kbd>Mod+I</kbd> | `toggleItalic()`, `setItalic()`, `unsetItalic()` |
| `Underline` | Mark | <kbd>Mod+U</kbd> | `toggleUnderline()`, `setUnderline()` |
| `Strike` | Mark | <kbd>Mod+Shift+X</kbd> | `toggleStrike()`, `setStrike()` |
| `Code` | Mark | <kbd>Mod+E</kbd> | `toggleCode()`, `setCode()` |
| `Heading` | Node | <kbd>Mod+Alt+[1-6]</kbd> | `toggleHeading({ level })`, `setHeading({ level })` |
| `Paragraph` | Node | <kbd>Mod+Alt+0</kbd> | `setParagraph()` |
| `BulletList` | Node | <kbd>Mod+Shift+8</kbd> | `toggleBulletList()` |
| `OrderedList` | Node | <kbd>Mod+Shift+7</kbd> | `toggleOrderedList()` |
| `Blockquote` | Node | <kbd>Mod+Shift+B</kbd> | `toggleBlockquote()` |
| `CodeBlock` | Node | <kbd>Mod+Alt+C</kbd> | `toggleCodeBlock({ language })` |
| `HorizontalRule` | Node | `---` (markdown input) | `setHorizontalRule()` |
| `History` | Extension | <kbd>Mod+Z</kbd>, <kbd>Mod+Shift+Z</kbd> | `undo()`, `redo()` |

---

## 3. Configuration & Overrides

Any bundled extension can be disabled or configured using `StarterKit.configure()`:

```tsx
StarterKit.configure({
  // Disable specific extensions
  strike: false,
  codeBlock: false,

  // Pass custom options to an extension
  heading: {
    levels: [1, 2, 3], // Only allow H1, H2, H3
  },

  history: {
    depth: 100, // Customize undo stack limit
  },
})
```
