# BlocksKit

`BlocksKit` provides modular block architecture for building Notion-level documents. It introduces drag handles, slash command palettes, multi-column containers, and collapsible toggles.

---

## 1. Quick Start

```tsx
import { useNotiq } from '@collabchron/notiq'
import { StarterKit } from '@collabchron/notiq/starter-kit'
import { BlocksKit } from '@collabchron/notiq/blocks-kit'

const editor = useNotiq({
  extensions: [
    StarterKit,
    BlocksKit.configure({
      handles: true,
      slashMenu: true,
      columns: true,
      callouts: true,
      toggles: true,
    }),
  ],
})
```

---

## 2. Options Reference

| Option | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `headless` | `boolean` | `false` | Suppresses default React/Tailwind UI for `SlashMenu` and `BlockHandle`. |
| `handles` | `boolean \| BlockHandleOptions` | `true` | Enables hoverable 6-dot drag grip handle (supports `headless`, `render`, `renderTargetLine`, `onStateChange`). |
| `slashMenu` | `boolean \| SlashMenuOptions` | `true` | Enables `/` command palette (supports `headless`, `render`, `onStateChange`). |
| `renderers` | `NotiqNodeRenderers` | `undefined` | Custom React renderers for rich decorator nodes (`hint`, `excalidraw`, `poll`, `image`, `inlineImage`). |
| `columns` | `boolean \| ColumnOptions` | `true` | Enables 2, 3, and 4 multi-column layout blocks with drag resize dividers. |
| `callouts` | `boolean` | `true` | Enables colored alert callout blocks with customizable emoji icons. |
| `toggles` | `boolean` | `true` | Enables collapsible toggle blocks with smooth height animation. |

---

## 3. Headless & Custom Node Renderers

You can run `BlocksKit` completely headless and supply your own UI components for slash commands, block drag handles, and rich decorator nodes (`hint`, `excalidraw`, `poll`, `image`, `inlineImage`):

```tsx
import { BlocksKit, NotiqContent, NotiqNodeRendererProvider } from '@collabchron/notiq/react'

const editor = useNotiq({
  extensions: [
    StarterKit,
    BlocksKit.configure({
      headless: true,
      slashMenu: {
        render: ({ options, selectedIndex, selectOptionAndCleanUp }) => (
          <ul>
            {options.map((opt, i) => (
              <li
                key={opt.key}
                data-active={i === selectedIndex}
                onClick={() => selectOptionAndCleanUp(opt)}
              >
                {opt.title}
              </li>
            ))}
          </ul>
        ),
      },
      handles: {
        render: ({ menuRef, insertBelow, remove, askAI }) => (
          <div ref={menuRef}>
            <button onClick={insertBelow}>+</button>
            <button onClick={askAI}>AI</button>
            <button onClick={remove}>Delete</button>
          </div>
        ),
      },
      renderers: {
        hint: ({ type, emoji, captionEditor }) => (
          <aside data-variant={type}>{emoji}</aside>
        ),
      },
    }),
  ],
})

// Or override node renderers at the React tree level:
<NotiqContent editor={editor} renderers={{ poll: CustomPoll }} />
```

## 4. Chained Commands

BlocksKit registers the following commands:

```ts
// Open slash palette at current cursor
editor.chain().focus().openSlashMenu().run()

// Insert multi-column grid
editor.chain().focus().insertColumns({ cols: 2 }).run()

// Insert callout alert
editor.chain().focus().insertCallout({
  variant: 'warning', // 'info' | 'warning' | 'success' | 'danger'
  icon: '⚠️',
}).run()

// Insert toggle collapsible block
editor.chain().focus().insertToggle({
  title: 'Toggle Section',
  open: false,
}).run()

// Convert current block type
editor.chain().focus().transformBlock('heading', { level: 2 }).run()
```
