# NotiqEditor API Reference

The `NotiqEditor` class is the central controller managing state, extensions, keyboard shortcuts, and document transactions.

An instance is created automatically by `useNotiq()` or `useEditor()`, or instantiated manually via `new NotiqEditor(options)`.

---

## 1. Instance Methods

### Document Content

#### `getHTML(): string`
Returns the current document serialized as clean semantic HTML.

#### `getJSON(): Record<string, any>`
Returns the document as a lossless JSON Lexical AST structure.

#### `getText(): string`
Returns the raw plain-text content of the document with line breaks.

#### `getMarkdown(): string`
Returns the document formatted as GitHub Flavored Markdown (GFM).

#### `setContent(content: string | Record<string, any>, emitUpdate?: boolean): void`
Replaces the entire document content. Accepts HTML, Markdown, or JSON AST.

#### `clearContent(emitUpdate?: boolean): void`
Clears the document, resetting it to an empty root paragraph block.

---

### Selection & Focus

#### `focus(position?: 'start' | 'end' | 'all' | number): NotiqEditor`
Focuses the editor and places the caret at the designated target position.

#### `blur(): NotiqEditor`
Removes focus from the editor DOM node.

#### `isFocused: boolean`
Returns `true` if the editor currently has browser focus.

#### `isEmpty: boolean`
Returns `true` if the document contains no text or non-paragraph nodes.

#### `isEditable: boolean`
Returns `true` if the editor is in editable mode; `false` if read-only.

---

### Command Execution

#### `chain(): ChainedCommands`
Initiates a fluent, chainable command sequence. Call `.run()` at the end to commit the transaction.

#### `can(): CanCommands`
Returns a chain builder that evaluates whether commands can execute without applying any AST mutations (dry-run).

#### `commands: Record<string, (...args: any[]) => boolean>`
Direct access to registered extension commands for single-shot invocation.

---

## 2. Event Listeners

Subscribe to editor lifecycle events with `.on()` and unsubscribe with `.off()`:

```ts
// Subscribe
editor.on('update', ({ editor }) => {
  console.log('Document modified')
})

editor.on('selectionUpdate', ({ editor }) => {
  console.log('Selection changed')
})

editor.on('focus', ({ editor, event }) => {
  console.log('Editor focused')
})

editor.on('blur', ({ editor, event }) => {
  console.log('Editor blurred')
})

editor.on('destroy', () => {
  console.log('Editor destroyed')
})
```
