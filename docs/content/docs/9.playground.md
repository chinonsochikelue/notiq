# Interactive Playground

Experiment with the full capabilities of Notiq directly in your browser.

::playground-iframe
::

---

## What to Try in the Sandbox:

1. **Notion Block Grips**: Hover over any paragraph or heading on the left margin to reveal the 6-dot drag grip. Click to open block transformation options or drag to reorder.
2. **Slash Command Menu**: Press <kbd>/</kbd> on any blank line to trigger the command palette. Type to filter commands and press <kbd>Enter</kbd> to insert.
3. **Canvas Mode Switcher**: Click the **Canvas Mode** button in the header to switch from standard linear document mode into the infinite 2D spatial canvas with pan and zoom.
4. **Real-Time Collaboration**: Open this playground in two side-by-side browser windows to observe sub-millisecond CRDT updates and live remote cursor presence.
5. **Fluent API Console**: Open your browser developer console (<kbd>F12</kbd>) to view AST state dumps and transaction payloads in real time.
