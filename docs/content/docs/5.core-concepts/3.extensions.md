# Authoring Extensions

Notiq is 100% modular. Core features (bold, italic, headings, lists) are built as first-class extensions. You can author your own custom extensions to add specialized markup, integrations, or shortcuts.

---

## 1. Extension Types

There are three primary extension primitives:

1. **`Extension`**: Adds custom commands, keyboard shortcuts, or event listeners without creating new AST node types.
2. **`Node`**: Introduces a new block or inline AST element into the document tree (e.g. Callout, Tweet, Image, CanvasCard).
3. **`Mark`**: Formats existing text inline (e.g. Highlight, Strikethrough, Color, Comment).

---

## 2. Creating a Custom Extension

Use `Extension.create()` to declare your extension:

```ts
import { Extension } from '@collabchron/notiq'

export interface MentionOptions {
  trigger: string
  suggestionLimit: number
}

export const Mention = Extension.create<MentionOptions>({
  name: 'mention',

  // 1. Default options
  addOptions() {
    return {
      trigger: '@',
      suggestionLimit: 5,
    }
  },

  // 2. Custom commands callable via editor.commands or editor.chain()
  addCommands() {
    return {
      insertMention: (user: { id: string; name: string }) => ({ chain }) => {
        return chain()
          .insertContent(`<span data-type="mention" data-id="${user.id}">@${user.name}</span> `)
          .run()
      },
    }
  },

  // 3. Custom keyboard shortcuts
  addKeyboardShortcuts() {
    return {
      '@': () => {
        console.log('Mention trigger detected')
        return false // let character pass through
      },
    }
  },
})
```

## 3. Registering Your Extension

Pass your custom extension into the `extensions` array in `useNotiq`:

```tsx
import { useNotiq } from '@collabchron/notiq'
import { StarterKit } from '@collabchron/notiq/starter-kit'
import { Mention } from './Mention'

export function App() {
  const editor = useNotiq({
    extensions: [
      StarterKit,
      Mention.configure({
        trigger: '@',
        suggestionLimit: 10,
      }),
    ],
  })

  return (
    <button
      onClick={() => {
        editor?.commands.insertMention({ id: 'usr_42', name: 'Alex' })
      }}
    >
      Insert @Alex
    </button>
  )
}
```

## 4. Under the Hood: Lexical Node Bridges

When authoring custom block nodes (`Node.create`), Notiq bridges your schema directly to Lexical's `LexicalNode` class hierarchy (`ElementNode` or `DecoratorNode`).

This ensures your custom nodes participate in:
- Double-buffered AST dirty checking
- Lossless serialization (`$generateHtmlFromNodes`)
- Undo / redo history tracking
- Yjs CRDT synchronization across remote peers
