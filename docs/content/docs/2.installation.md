# Installation

Get started with Notiq in your React, Next.js, or Vite application in less than a minute.

---

## 1. Package Installation

Install Notiq and its dependencies via your preferred package manager:

::code-group
```bash [pnpm]
pnpm add @collabchron/notiq
```
```bash [npm]
npm install @collabchron/notiq
```
```bash [yarn]
yarn add @collabchron/notiq
```
```bash [bun]
bun add @collabchron/notiq
```
::

> [!TIP]
> Notiq is fully typed and includes zero runtime dependency bloat. Meta's Lexical core is bundled and isolated internally, so you never encounter Lexical version mismatch errors.

---

## 2. Basic Headless Editor Setup

Notiq is completely headless — you control 100% of the UI, styling, and markup while Notiq manages the AST reconciliation, history stack, and keyboard navigation.

Create a new component `src/components/Editor.tsx`:

```tsx [src/components/Editor.tsx]
'use client'

import React from 'react'
import { useNotiq, NotiqContent } from '@collabchron/notiq'
import { StarterKit } from '@collabchron/notiq/starter-kit'

export function Editor() {
  const editor = useNotiq({
    extensions: [StarterKit],
    content: '<p>Hello from <strong>Notiq</strong>! Press <kbd>/</kbd> for blocks.</p>',
    onUpdate: ({ editor }) => {
      console.log('Document updated:', editor.getHTML())
    },
  })

  if (!editor) {
    return null
  }

  return (
    <div className="max-w-3xl mx-auto my-12 border border-zinc-800 rounded-2xl bg-zinc-950 p-6 text-zinc-100 shadow-xl">
      {/* Custom Headless Toolbar */}
      <div className="flex items-center gap-2 pb-4 mb-4 border-b border-zinc-800">
        <button
          type="button"
          onClick={() => editor.chain().focus().toggleBold().run()}
          className={`px-3 py-1.5 text-xs font-semibold rounded-lg transition-colors ${
            editor.isActive('bold') ? 'bg-emerald-600 text-white shadow-sm' : 'bg-zinc-800 hover:bg-zinc-700 text-zinc-300'
          }`}
        >
          Bold
        </button>

        <button
          type="button"
          onClick={() => editor.chain().focus().toggleItalic().run()}
          className={`px-3 py-1.5 text-xs font-semibold rounded-lg transition-colors ${
            editor.isActive('italic') ? 'bg-emerald-600 text-white shadow-sm' : 'bg-zinc-800 hover:bg-zinc-700 text-zinc-300'
          }`}
        >
          Italic
        </button>

        <button
          type="button"
          onClick={() => editor.chain().focus().toggleHeading({ level: 2 }).run()}
          className={`px-3 py-1.5 text-xs font-semibold rounded-lg transition-colors ${
            editor.isActive('heading', { level: 2 }) ? 'bg-emerald-600 text-white shadow-sm' : 'bg-zinc-800 hover:bg-zinc-700 text-zinc-300'
          }`}
        >
          H2
        </button>

        <button
          type="button"
          onClick={() => editor.chain().focus().undo().run()}
          disabled={!editor.can().undo()}
          className="ml-auto px-2.5 py-1 text-xs rounded bg-zinc-900 border border-zinc-800 hover:bg-zinc-800 text-zinc-400 disabled:opacity-40"
        >
          Undo
        </button>
      </div>

      {/* Render Headless Editable Area */}
      <NotiqContent editor={editor} className="min-h-[250px] outline-none prose prose-invert" />
    </div>
  )
}
```

## 3. Adding Notion Blocks (BlocksKit)

To enable Notion-style block drag handles, 6-dot grip menus, slash commands (`/`), and multi-column layouts, install and configure `BlocksKit`:

::code-group
```bash [pnpm]
pnpm add @collabchron/notiq-blocks
```
```bash [npm]
npm install @collabchron/notiq-blocks
```
```bash [yarn]
yarn add @collabchron/notiq-blocks
```
```bash [bun]
bun add @collabchron/notiq-blocks
```
::

Configure it in your editor:

```tsx [src/components/NotionEditor.tsx]
'use client'

import { useNotiq, NotiqContent } from '@collabchron/notiq'
import { StarterKit } from '@collabchron/notiq/starter-kit'
import { BlocksKit } from '@collabchron/notiq/blocks-kit'

export function NotionEditor() {
  const editor = useNotiq({
    extensions: [
      StarterKit,
      BlocksKit.configure({
        handles: true,
        slashMenu: true,
        columns: true,
        callouts: true,
      }),
    ],
  })

  return <NotiqContent editor={editor} />
}
```

## 4. Tiptap Alias Compatibility

If your existing codebase uses Tiptap imports (`useEditor`, `EditorContent`), Notiq exports zero-overhead compatibility aliases:

```tsx [src/components/TiptapCompatible.tsx]
import { useEditor, EditorContent } from '@collabchron/notiq'
import { StarterKit } from '@collabchron/notiq/starter-kit'

// Exactly identical signature and functionality!
const editor = useEditor({
  extensions: [StarterKit],
  content: '<p>Zero-friction migration from Tiptap.</p>',
})

return <EditorContent editor={editor} />
```
