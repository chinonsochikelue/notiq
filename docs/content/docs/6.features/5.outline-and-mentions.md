Notiq `v1.3.0` ships two productivity primitives out of the box: a **Live Table of Contents (`TableOfContentsPlugin`)** with scroll-spy and **`@` Collaborator Mentions & Smart Date Chips (`MentionsPlugin` / `MentionNode`)**.

---

## 1. Live Table of Contents (`TableOfContentsPlugin`)

`TableOfContentsPlugin` is mounted automatically inside `<Editor />` and displays a collapsible floating **Outline** pill/panel whenever a document has at least `minHeadings` (default `2`) headings.

- Tracks `H1`–`H3` nodes in real time via Lexical's `registerUpdateListener`.
- Highlights the active heading automatically via viewport scroll-spy.
- Smoothly scrolls to any heading on click.

### Headless Hook (`useTableOfContents`)

Use `useTableOfContents` (or pass a `children` render prop to `TableOfContentsPlugin`) to build your own sidebar or outline UI:

```tsx
import { useTableOfContents } from '@collabchron/notiq'

function CustomOutline() {
  const { headings, activeKey, scrollToHeading } = useTableOfContents({
    maxLevel: 3,
  })

  return (
    <nav aria-label="Document outline">
      {headings.map((heading) => (
        <button
          key={heading.key}
          type="button"
          onClick={() => scrollToHeading(heading.key)}
          data-active={activeKey === heading.key}
        >
          {heading.text}
        </button>
      ))}
    </nav>
  )
}
```

## 2. `@` Collaborator Mentions & Smart Date Chips

Type `@` anywhere in the editor to open the `MentionsPlugin` autocomplete menu:

- **Live Collaborators**: Automatically lists peers currently connected to the Yjs collaboration room (via `useOptionalCollab()`), complete with avatars and cursor colors.
- **Smart Date Chips**: Type `@today`, `@tomorrow`, or `@yesterday` to insert formatted inline date pills (`📅 Nov 18, 2026`).
- **Atomic `MentionNode`**: Mentions serialize cleanly to JSON (`type: "mention"`) and HTML (`data-lexical-mention`), and behave as atomic inline entities (`isTextEntity()`).

```tsx
import { $createMentionNode, $isMentionNode, MentionNode } from '@collabchron/notiq'

// Programmatic insertion inside editor.update(...)
const userChip = $createMentionNode('Alice', { kind: 'user' })
const dateChip = $createMentionNode('📅 Nov 18, 2026', {
  kind: 'date',
  text: '📅 Nov 18, 2026',
})
```
