# Real-Time Collaboration

Notiq includes first-class support for multiplayer collaboration powered by **Yjs**, the industry-standard Conflict-Free Replicated Data Type (CRDT) engine.

Multiple users can edit the same document simultaneously with zero merge conflicts, sub-millisecond sync, and visual awareness cursors.

---

## 1. Client Setup with CollabKit

```tsx
import React, { useMemo } from 'react'
import * as Y from 'yjs'
import { WebsocketProvider } from 'y-websocket'
import { useNotiq, NotiqContent } from '@collabchron/notiq'
import { StarterKit } from '@collabchron/notiq/starter-kit'
import { CollabKit } from '@collabchron/notiq/collab-kit'

export function CollaborativeEditor({ documentId, currentUser }) {
  // 1. Initialize persistent Yjs Doc and WebSocket Provider
  const { doc, provider } = useMemo(() => {
    const ydoc = new Y.Doc()
    const wsProvider = new WebsocketProvider(
      'ws://localhost:4444',
      documentId,
      ydoc
    )
    return { doc: ydoc, provider: wsProvider }
  }, [documentId])

  // 2. Configure Notiq with CollabKit
  const editor = useNotiq({
    extensions: [
      StarterKit,
      CollabKit.configure({
        document: doc,
        user: {
          name: currentUser.name,
          color: currentUser.color || '#8b5cf6',
        },
      }),
    ],
  })

  return (
    <div>
      {/* Remote presence indicator */}
      <div className="flex items-center gap-2 mb-4 text-xs text-zinc-400">
        <span className="w-2 h-2 rounded-full bg-emerald-500 animate-pulse" />
        Connected to Room: {documentId}
      </div>

      <NotiqContent editor={editor} />
    </div>
  )
}
```

## 2. Remote Cursor Awareness

CollabKit tracks cursor positions and selections through the Yjs awareness protocol:

- Each collaborator's caret is rendered with their assigned color and name tag.
- Selection ranges are drawn using translucent color overlays that update in real time.
- Idle timeouts automatically fade out inactive user carets.

---

## 3. Offline-First Durability (IndexedDB)

Combine `y-indexeddb` with Notiq to enable instant offline editing. When the user reconnects, changes sync seamlessly:

```ts
import { IndexeddbPersistence } from 'y-indexeddb'

const indexeddbProvider = new IndexeddbPersistence('notiq-doc-store', doc)
indexeddbProvider.on('synced', () => {
  console.log('Document loaded from local offline cache')
})
```

## 4. Collab WebSocket Server

Notiq includes a self-hosted Yjs WebSocket server at `server/collab-server.mjs` (and also works with any standard `y-websocket`, Hocuspocus, or Cloudflare Durable Objects backend):

```bash
# Run locally on port 4444
node server/collab-server.mjs
```

### Cloud Deployment & Environment Variables

When deploying `server/collab-server.mjs` to Railway, Render, or Fly.io:

- **Start Command**: `node server/collab-server.mjs` (automatically reads `process.env.PORT || process.env.COLLAB_PORT || 4444`)
- **Healthcheck Path**: `/health`
- **Frontend Env Var**: Set `NEXT_PUBLIC_COLLAB_SERVER_URL=wss://<your-collab-host>` in your Next.js / Vercel environment so `CollabContext` connects automatically.
