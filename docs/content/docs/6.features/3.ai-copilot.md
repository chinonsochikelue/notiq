# AI Copilot & Research

Notiq ships with **AICopilot** (also exported as **`AIKit`**) and **`AICommandBar`**, combining an inline ghost-text completion engine with a `Cmd/Ctrl + K` AI Command Bar that thinks, researches live web sources, and streams directly into native Notiq blocks.

---

## 1. Quick Setup

```tsx
import { useNotiq, NotiqContent } from '@collabchron/notiq'
import { StarterKit } from '@collabchron/notiq/starter-kit'
import { AICopilot } from '@collabchron/notiq'

export function AiEditor() {
  const editor = useNotiq({
    extensions: [
      StarterKit,
      AICopilot.configure({
        enabled: true, // Enables InlineCopilotPlugin + AICommandBar
      }),
    ],
  })

  return <NotiqContent editor={editor} />
}
```

> [!TIP]
> `AICopilot` automatically includes `AICommandBar`. If you only want the `Cmd/Ctrl + K` command bar without inline ghost-text completions, register `AICommandBar` directly or set `AICopilot.configure({ enabled: false })`.

---

## 2. Triggering AI Actions

Users can invoke AI anywhere in the document:

1. **Keyboard Shortcut (`Cmd+K` / `Ctrl+K`)**: Opens the floating AI Command Bar anchored to the current selection or block.
2. **Slash Menu (`/`)**: Choose **Ask AI Assistant** from `/`.
3. **Inline Ghost-Text Copilot (`Alt+C`)**: Toggle real-time ghost-text suggestions while typing; press `Tab` to accept.
4. **Programmatic Dispatch**:

```ts
// Open the AI Command Bar with an optional preset action or prompt
editor.chain().focus().openAICommandBar({
  action: 'ImproveWriting',
}).run()

editor.chain().focus().openAICommandBar({
  initialPrompt: 'Draw an architecture diagram for this system',
}).run()
```

## 3. Thinking Mode & Topic-Aware Web Research

The AI Command Bar includes two toggleable modes right below the prompt input:

- **Think Mode**: Instructs the model to emit a concise `<thinking>...</thinking>` reasoning trace before generating content. Notiq streams this into a collapsible **AI Reasoning** drawer so the main editor stays clean, and keeps a **Thoughts** toggle available during review.
- **Research Mode**: Automatically extracts the topic from the document context (or custom question), queries **DuckDuckGo Instant Answer** and **Wikipedia** in parallel with keyword-relevance filtering, and injects verified summaries into the prompt. Extracted citations appear as clickable **Research Sources** pills in the review bar without polluting the document body.

## 4. Rich In-Canvas Block Streaming & Hydration

Instead of dumping plain text, Notiq's streaming pipeline (`serializeMarkdownToNodes` + `NOTIQ_TRANSFORMERS`) hydrates Markdown into native Lexical nodes in real time with purple AI highlights and a pulsing caret:

| Feature | Markdown Syntax | Rendered Notiq Block |
| :--- | :--- | :--- |
| **Excalidraw Diagrams** | ```` ```excalidraw ... ``` ```` | Interactive `ExcalidrawNode` SVG preview (double-click to edit) |
| **Callouts** | `> [!NOTE]`, `> [!TIP]`, `> [!WARNING]`, `> [!IMPORTANT]` | Styled `Hint` callout box with inline formatting |
| **Tables** | Standard GFM `\| Col \| ... \|` | Native `TableNode` with bold, italic, code, links & math in cells |
| **Normal Images** | `![Alt](https://...)` | Full-width block `ImageNode` |
| **Inline Floated Images** | `![inline:left:Alt](https://...)` or `![inline:right:Alt](https://...)` | Floated `InlineImageNode` alongside text |
| **KaTeX Math** | `$E = mc^2$` or `$$\n...\n$$` | Inline and block `EquationNode` |

### Excalidraw Diagram Generation

When asked to draw a diagram, flowchart, or architecture (or via the **Draw diagram (Excalidraw)** preset), Notiq:
1. Displays a clean `> 🎨 Drawing interactive Excalidraw diagram...` placeholder while the JSON block streams.
2. Compiles declarative `{ nodes, edges }`, simplified element arrays (with `label`s), or full Excalidraw scenes via `compileExcalidrawDiagram` & `normalizeExcalidrawElements`.
3. Renders an adaptive light/dark SVG preview with `skipInliningFonts: true` for zero-error Turbopack/Next.js compatibility.

## 5. Review, Interactive Diff & Accept/Discard Bar

Once streaming completes, the Command Bar switches to review mode:

- **Accept (`Cmd/Ctrl + Enter`)**: Strips the temporary AI highlight styling and commits the generated blocks to document history.
- **Discard (`Escape`)**: Removes the generated blocks and restores the original selection/block snapshot.
- **Interactive Diff (Per-Hunk Accept / Reject)**: Click **Diff** when refining selected text to inspect word-level hunks (`buildDiffHunks` / `resolveDiffHunks`). Click **✓** (Accept) or **✕** (Reject) on any individual hunk—or use **Accept All** / **Reject All**—to merge selective changes into the live editor preview before committing.
- **Refine**: Type a follow-up instruction (e.g., *"shorter"*, *"add a comparison table"*) to iterate on the generated output.
- **Retry**: Re-runs the last request.

## 6. Multi-Provider Backend (`/api/ai`)

Notiq's built-in `/api/ai` route handler supports:
- **Groq** (`GROQ_API_KEY`)
- **Google Gemini** (`GOOGLE_GENERATIVE_AI_API_KEY` / `GEMINI_API_KEY`)
- **OpenAI** (`OPENAI_API_KEY`)
- **Zero-Config Smart Fallback**: Built-in contextual generator when no external API key is configured, including interactive Excalidraw diagrams, tables, callouts, and thinking traces.

## 7. Headless Mode & Custom Renderers

Both `AICopilot` and `AICommandBar` support `headless`, `render`, `onStateChange`, and `apiEndpoint` options so you can keep Notiq's streaming, thinking, research, and block-hydration engine while rendering your own UI:

```tsx
AICopilot.configure({
  headless: true,
  apiEndpoint: '/api/ai',
  render: ({ suggestion, accept, dismiss }) =>
    suggestion ? <span onClick={accept}>{suggestion}</span> : null,
  commandBar: {
    headless: true,
    render: ({ isOpen, prompt, setPrompt, submit, status, accept, discard }) =>
      isOpen ? (
        <div>
          <input value={prompt} onChange={(e) => setPrompt(e.target.value)} />
          <button onClick={() => submit()}>Run ({status})</button>
          <button onClick={accept}>Accept</button>
          <button onClick={discard}>Discard</button>
        </div>
      ) : null,
  },
})
```
