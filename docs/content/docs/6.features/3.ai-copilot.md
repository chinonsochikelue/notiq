# Generative AI Copilot

Notiq provides native **AiKit**, empowering your editor with streaming LLM completions, inline text transformations, and contextual prompt menus without requiring expensive proprietary cloud subscriptions.

---

## 1. Quick Setup with AiKit

```tsx
import { useNotiq, NotiqContent } from '@collabchron/notiq'
import { StarterKit } from '@collabchron/notiq/starter-kit'
import { AiKit } from '@collabchron/notiq/ai-kit'

export function AiEditor() {
  const editor = useNotiq({
    extensions: [
      StarterKit,
      AiKit.configure({
        endpoint: '/api/ai/complete', // Your streaming backend route
        model: 'gemini-1.5-flash',
        shortcut: 'Mod-j', // Cmd+J or Ctrl+J to open AI prompt
      }),
    ],
  })

  return <NotiqContent editor={editor} />
}
```

---

## 2. Triggering AI Prompts

Users can trigger AI assistance via:

1. **Empty Line `<Space>`**: Pressing space on a new line opens the inline prompt input: *"Ask AI to write anything..."*.
2. **Keyboard Shortcut (`Cmd+J` / `Ctrl+J`)**: Opens the AI action modal over the current selection.
3. **Programmatic Dispatch**:

```ts
// Ask AI with custom prompt
editor.chain().focus().aiPrompt({ prompt: 'Draft a project roadmap for Q3' }).run()

// Rewrite selected text
editor.chain().focus().aiTransform({ action: 'improve_writing' }).run()
editor.chain().focus().aiTransform({ action: 'summarize' }).run()
editor.chain().focus().aiTransform({ action: 'fix_spelling' }).run()
editor.chain().focus().aiTransform({ action: 'translate', targetLanguage: 'Spanish' }).run()
```

---

## 3. Streaming Diff & Accept/Reject UI

AiKit streams tokens directly into a shadow AST overlay. The user sees the text appearing with animated ghost highlights, accompanied by an accept/discard bar:

- **Accept (`Enter`)**: Commits the generated tokens into the real document history.
- **Discard (`Escape`)**: Reverts the document to its original state instantly.
- **Try Again**: Re-submits the prompt with higher temperature for alternative variations.

## 4. Custom Backend Adapter Example (Next.js / Node)

Here is a standard streaming route using the AI SDK or Google Gemini:

```ts [app/api/ai/complete/route.ts]
import { GoogleGenAI } from '@google/genai'

const ai = new GoogleGenAI()

export async function POST(req: Request) {
  const { prompt, context } = await req.json()

  const response = await ai.models.generateContentStream({
    model: 'gemini-2.5-flash',
    contents: `Document Context:\n${context}\n\nUser Prompt: ${prompt}`,
  })

  // Return standard SSE stream to Notiq AiKit
  return new Response(response.toTextStreamResponse().body, {
    headers: { 'Content-Type': 'text/event-stream' },
  })
}
```
