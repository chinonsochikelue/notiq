# Chained Commands

One of Notiq's signature superpowers is the **Chainable Command API**. Instead of manually managing selections, dispatching raw events, and tracking transaction state, you chain operations fluently and terminate with `.run()`.

---

## 1. The Anatomy of a Chain

Every chained transaction follows this sequence:

```ts
editor
  .chain()          // 1. Begin chain transaction
  .focus()          // 2. Ensure editor has focus
  .toggleBold()     // 3. Queue bold toggle
  .setColor('#a855f7') // 4. Queue color mark
  .run()            // 5. Commit atomic transaction
```

If you omit `.run()`, the queued commands are discarded without mutating the document.

---

## 2. Common Chained Commands

### Text Formatting (Marks)

```ts
// Toggle basic marks
editor.chain().focus().toggleBold().run()
editor.chain().focus().toggleItalic().run()
editor.chain().focus().toggleUnderline().run()
editor.chain().focus().toggleStrike().run()
editor.chain().focus().toggleCode().run()

// Explicit set or unset
editor.chain().focus().setBold().run()
editor.chain().focus().unsetBold().run()
```

### Headings & Typography

```ts
// Headings levels 1 through 6
editor.chain().focus().toggleHeading({ level: 1 }).run()
editor.chain().focus().toggleHeading({ level: 2 }).run()
editor.chain().focus().toggleHeading({ level: 3 }).run()

// Reset to standard paragraph
editor.chain().focus().setParagraph().run()
```

### Lists & Structure

```ts
editor.chain().focus().toggleBulletList().run()
editor.chain().focus().toggleOrderedList().run()
editor.chain().focus().toggleTaskList().run()
editor.chain().focus().toggleBlockquote().run()
editor.chain().focus().toggleCodeBlock({ language: 'typescript' }).run()
```

### Content Insertion

```ts
// Insert HTML, markdown, or plain string at current selection
editor.chain().focus().insertContent('<p>Inserted paragraph!</p>').run()

// Clear entire document
editor.chain().focus().clearContent().run()
```

## 3. Dry-Run Validation (`editor.can()`)

When building accessible toolbars, you often want to disable buttons if an action is currently invalid (e.g., cannot indent further, or cannot undo when the history stack is empty).

Notiq provides `editor.can()` to preview transactions without executing them:

```tsx
// Check if Undo is possible
const canUndo = editor.can().chain().undo().run()

// Check if Heading 1 can be applied
const canH1 = editor.can().chain().toggleHeading({ level: 1 }).run()

return (
  <button
    disabled={!canUndo}
    onClick={() => editor.chain().focus().undo().run()}
    className="disabled:opacity-40 disabled:cursor-not-allowed"
  >
    Undo
  </button>
)
```

---

## 4. Custom Chains

You can compose multiple complex steps into reusable commands:

```ts
function insertCalloutWithHeading(editor, title: string, body: string) {
  editor
    .chain()
    .focus()
    .insertCallout({ variant: 'info' })
    .insertContent(`<h4>${title}</h4><p>${body}</p>`)
    .run()
}
```
