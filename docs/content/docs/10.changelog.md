## v1.5.0

**Released:** November 2026 · **Package:** `@collabchron/notiq@1.5.0` · **Tag:** `Latest`

### Highlights

- **Persistent Block `UniqueIDPlugin`**: Assigns stable `data-notiq-block-id` attributes across top-level blocks so external integrations, deep links, and RAG indexers can reference individual blocks reliably.
- **Word & Character Count (`CharacterCountPlugin`, `useCharacterCount`)**: Live words, characters, reading-time footer bar, and optional `maxCharacters` limit tracking.
- **`:emoji:` Shortcode Picker (`EmojiPickerPlugin`)**: Instant `:` typeahead autocomplete across aliases, tags, and descriptions.
- **Client-Side DOCX Import & Export**: Export formatted Lexical documents to `.docx` (`docx`) and import `.docx` files (`mammoth`) directly in the browser via `ImportExportModal` or `/docx`.
- **Headless Document REST API & Durable Persistence**: `GET /docs`, `GET /docs/:room`, `POST`/`PUT /docs/:room`, and `DELETE /docs/:room` in `collab-server`, backed by optional `COLLAB_DATA_DIR` `.yjs` disk snapshots and `COLLAB_API_KEY` Bearer auth.

### Upgrade

```bash
npm install @collabchron/notiq@1.5.0
```

## v1.4.0

**Released:** November 2026 · **Package:** `@collabchron/notiq@1.4.0`

::promo-video-showcase
::

### Highlights

- **Database Table & Kanban Board (`DatabaseNode`)**: Insert structured task databases via `/database` or `/kanban`. Supports inline editing for title, status (`To Do`, `In Progress`, `Done`), priority (`Low`, `Medium`, `High`), tags, and due dates, plus search/status filtering, sorting, and drag-and-drop Kanban columns.
- **`[[Page]]` Links & Backlinks (`PageLinkNode`, `PageLinksPlugin`)**: Type `[[` to open a typeahead menu linking to workspace rooms, sub-pages, or headings within the current document (including creating new page links on the fly), paired with a collapsible **Page Links & Backlinks** footer.
- **Image Lightbox & Paste/Drop Polish (`ImageLightbox`)**: Added a full-screen portal lightbox with `0.5x–3x` zoom controls, mouse-wheel zoom, download action, and `Escape` / `+` / `-` / `0` keyboard shortcuts on both `ImageComponent` and `InlineImageComponent`. Upgraded `DragDropPastePlugin` with `image/svg+xml` vector support and an optional `onUploadImage` async uploader with data-URL fallback.
- **Upgraded Inline Image UI**: Responsive `left` / `right` / `full` positioning, a glassmorphic floating action pill (align, caption toggle, edit modal, delete), bottom-right drag-to-resize handle with live `width × height` readout, broken-image fallback, and modernized `InsertInlineImageDialog` (`Upload File` dropzone + `From URL` tabs) & `UpdateInlineImageDialog`.

### Fixes & Chore

- **Collaboration Mobile Header**: Wrapped `/collaboration` header controls cleanly on `< sm` viewports so `ModeToggle` never clips off-screen.
- **Mentions Card Interaction**: Added `anchorClassName="z-[9999] pointer-events-auto"` and `overscroll-contain` on `MentionsPlugin` and `MentionsAutocomplete` so hovering shows `cursor-pointer` and long lists scroll smoothly.
- **Security**: Upgraded `next` and `eslint-config-next` from `16.4.3` to `16.4.6`.

### Upgrade

```bash
npm install @collabchron/notiq@1.4.0
```

## v1.3.0

**Released:** November 2026 · **Package:** `@collabchron/notiq@1.3.0`

### Highlights

- **`@Mentions` & Smart Date Chips (`MentionsPlugin`, `MentionNode`)**: Type `@` in the editor to mention live collaborators from `CollabContext` or insert smart date chips (`@today`, `@tomorrow`, `@yesterday`).
- **Per-Hunk AI Diff Review**: Interactive diff review bar allowing users to accept or reject individual AI-suggested hunks instead of all-or-nothing replacement.
- **Live Collaboration Server Default**: Wired `wss://www.notiqcollabserver.collabchron.com.ng` as the default WebSocket endpoint in `/collaboration` and `CollabContext` (`NEXT_PUBLIC_COLLAB_SERVER_URL`).
- **Table of Contents (`TableOfContentsPlugin`, `useTableOfContents`)**: Automatic heading extraction with scroll-spy active state.

### Upgrade

```bash
npm install @collabchron/notiq@1.3.0
```
